An Easy Proof of a Weak Version of Chernoff Inequality

Sariel Har-Peled∗

November 16, 2026

Abstract

We prove an easy but very1 weak version of Chernoff’s inequality [MR95;DP09;Mul18;Kus25]. Namely, that the probability that in 6𝑀6M throws of a fair coin, one gets at most 𝑀M heads is ≤1/2𝑀\leq 1/2^M.

1 The proof

Consider a game that starts with 𝑋0=2𝑀X_0 = 2^M balls. In the 𝑖ith iteration, you flip a fair coin 𝐶𝑖∈{0,1}C_i \in \{0,1\}. If 𝐶𝑖=1C_i=1, which happens with probability half, one throws away half the balls they currently have. Otherwise, all balls are kept to the next iteration. Let 𝑌𝑖Y_i be the number of balls you have after the 𝑖ith iteration, and observe that

𝔼[𝑌𝑖|𝑌𝑖−1]=𝑌𝑖−1/2+𝑌𝑖−1/4=(3/4)𝑌𝑖−1.\ExCond{Y_i}{Y_{i-1}} = Y_{i-1}/2 + Y_{i-1}/4 = (3/4)Y_{i-1}.

As such, we have

𝔼[𝑌𝑖]=𝔼[𝔼[𝑌𝑖|𝑌𝑖−1]]=𝔼[(3/4)𝑌𝑖−1]=(3/4)𝑖2𝑀.

Observe that (3/4)3=27/64≤1/2(3/4)^3 = 27/64 \leq 1/2. Thus, we have 𝔼[𝑌6𝑀]=(3/4)6𝑀2𝑀≤2𝑀−2𝑀=1/2𝑀.\mathbb{E}{}{\left[Y_{6M}\right]}=(3/4)^{6M}2^M\le2^{M-2M}=1/2^M. By Markov’s inequality, we have that

ℙ[∑𝑖=16𝑀𝐶𝑖≤𝑀]=ℙ[𝑌6𝑀≥1]≤𝔼[𝑌6𝑀]1≤12𝑀.

Remark 1.1. The above proof is essentially Azuma’s inequality proof without optimizing the constants. The magic is in using the formula 𝔼[𝔼[𝑋|𝑌]]=𝔼[𝑋].

Remark 1.2 (Connection to QuickSort). The proof came about from analyzing QuickSort. Indeed consider an element 𝑒e in an array of size 𝑛n being sorted by QuickSort, and let 𝑌𝑖Y_i be the size of the recursive subproblem containing 𝑒e in the 𝑖ith level of the recursion. 115\begin{abstract}
116 We prove an easy but very\footnote{More very{}s can be provided by
117 the author upon request.} weak version of Chernoff's
118 inequality \cite{mr-ra-95, dp-cmara-09, m-18-fpcba,
119 k-scapcbtg-25}. Namely, that the probability that in $6M$
120 throws of a fair coin, one gets at most $M$ heads is $\leq 1/2^M$.
121\end{abstract}
122
123\section{The proof}
124
125Consider a game that starts with $X_0 = 2^M$ balls. In the $i$\th
126iteration, you flip a fair coin $C_i \in \{0,1\}$. If $C_i=1$, which
127happens with probability half, one throws away half the balls they
128currently have. Otherwise, all balls are kept to the next iteration.
129Let $Y_i$ be the number of balls you have after the $i$\th iteration,
130and observe that
131\begin{equation*}
132 \ExCond{Y_i}{Y_{i-1}}
133 =%
134 Y_{i-1}/2 + Y_{i-1}/4 = (3/4)Y_{i-1}.
135\end{equation*}
136As such, we have
137\begin{equation*}
138 \Ex{Y_i}
139 =%
140 \Ex{\ExCond{Y_i}{Y_{i-1}} \bigr.}
141 =%
142 \Ex{(3/4)Y_{i-1}}
143 =
144 (3/4)^i 2^M.
145\end{equation*}
146Observe that $(3/4)^3 = 27/64 \leq 1/2$. Thus, we have
147\begin{math}
148 \Ex{Y_{6M}} = (3/4)^{6M} 2^M \leq 2^{M-2M } = 1/2^M.
149\end{math}
150By Markov's inequality, we have that
151\begin{equation*}
152 \Prob{ \sum\nolimits_{i=1}^{6M} C_i \leq M}
153 =%
154 \Prob{ Y_{6M} \geq 1 }
155 \leq
156 \frac{\Ex{Y_{6M}}}{1}
157 \leq
158 \frac{1}{2^M}.
159 \hspace{3cm}\tag*{\myqedsymbol}
160\end{equation*}
161
162\begin{remark}
163 The above proof is essentially Azuma's inequality proof without
164 optimizing the constants. The magic is in using the formula
165 $\Ex{\ExCond{X}{Y} \bigr.} =\Ex{X}$.
166\end{remark}
167\begin{remark}[Connection to \QuickSort]
168 The proof came about from analyzing \QuickSort. Indeed consider an
169 element $e$ in an array of size $n$ being sorted by \QuickSort,
170 and let $Y_i$ be the size of the recursive subproblem containing
171 $e$ in the $i$\th level of the recursion. A careful
172 analysis\footnote{Here is the not careful analysis. With
173 probability half the pivot for the subproblem of $Y_i$
174 ``succeeds'' to fall in the range
175 $[\tfrac{1}{4}Y_{i-1}, \tfrac{3}{4}Y_{i-1}]$. Then the size of
176 the larger subproblem is $(3/4)Y_{i-1}$. Otherwise, we get
177 nothing, and we pretend that $Y_i = Y_{i-1}$. Thus,
178 $\ExCond{Y_i}{Y_{i-1}} \leq (7/8)Y_{i-1}$.} shows that
179 $\ExCond{Y_i}{Y_{i-1}} \leq (3/4)Y_{i-1}$. The same proof now goes
180 through with $M=c\log_2 n$, to argue that the probability
181 \QuickSort recursion depth exceeds $6M$ is at most
182 $n \cdot 1 /2^{M} = 1/n^{c-1}$.
183\end{remark}
